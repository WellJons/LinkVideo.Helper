LinkVideo.Helper 3.0.18 RC (Windows)

Исправлен поиск камер B2O по VPN-портам
- Прежняя 3.0.17 находила камеры по логину, но сверяла порт
  только с основной карточкой камеры. В ней часто нет RTSP-адреса.
- Теперь для каждой найденной камеры B2O дополнительно читается
  существующий подтверждённый endpoint:
  GET /operators/{operator}/cameras/{id}/camera-streams-urls
- Из поля camera_stream_main извлекается только ЯВНО указанный
  RTSP-порт (например, :11690). Порт по умолчанию 554 не угадывается.
- Совпадение принимается только для камер, найденных у точного
  B2O-логина и в той же стране, что VPN-сервер. Неоднозначные
  и частично проверенные результаты не считаются подтверждёнными.
- VPN-логины с суффиксами _1, _3, ... сводятся к исходному логину
  только для поиска B2O. Другой логин можно ввести вручную.

Компактная карточка VPN-клиента
- ID подтверждённой камеры теперь выводится в СООТВЕТСТВУЮЩЕМ
  элементе списка портов, отдельной строкой НАД данными трафика.
- Большая повторяющаяся карточка «Камеры B2O по портам»
  внизу страницы удалена.
- Логин поиска B2O и кнопка «Сверить B2O» находятся в
  заголовочной части списка портов.
- Рядом кратко показано, сколько камер и RTSP-портов проверено,
  а также есть ли ошибки или неоднозначные совпадения.
- В показателях порта вместо «NAT» написано «Трафик порта».

Остаётся из версии 3.0.17:
- Библиотека шаблонов ответов, категории, изображения и DOCX.
- Улучшенная карточка VPN и пароль в виде обычного текста.
- Показ IP источника L2TP, счётчик портов активных учёток.
- Telegram-бот НЕ включён.

Безопасность:
- B2O запросы только GET, без изменения камер или VPN.
- URL с RTSP-паролями не записываются в интерфейс или логи.
- Установщик RC тестовый, стабильный канал не изменён.
- Проверить на реальных камерах и VPN следует до выпуска
  стабильного обновления для сотрудников.
