# LinkVideo.Helper 3.0.7 — UI Foundation

Первая ветка нового интерфейса. Бизнес-логика VPN, архива и диагностики перенесена из 3.0.7 без намеренного изменения протоколов.

Главная цель этой ветки — единая визуальная система: нейтральный фон, спокойные поверхности, современная типографика, компактная навигация, status chips и меньше рамок.

Google Sheets пока не подключается автоматически. В `GOOGLE_SHEETS_SYNC_SCHEMA_3.0.md` зафиксирована схема будущей полной сверки с RouterOS.

Для проверки без компиляции: `run.bat`.
