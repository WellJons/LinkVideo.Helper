LinkVideo.Helper 3.0.16 — тестовая версия

Новое: Россия / Ula, только чтение тарифов и стоимости.
- В разделе «Клиенты и тарифы» добавлена отдельная вкладка «Россия · Ula (тест)»; вкладки Беларуси и Казахстана сохранены.
- Импорт Ula.ini: локально извлекаются Server, Port, Sid и UserName, без копирования секретов в репозиторий или журнал.
- Ручная авторизация Oracle: пароль вводится на тестовом ПК и не сохраняется.
- Тест подключения, поиск клиента через devdb.get_clients_by_filter_ula (режим поиска требует проверки), точный выбор ID_CLIENT.
- Запрос услуг через crm.get_client_services_list с привязкой ID и флагов; отдельная таблица SERVICE_NAME, TARIFF_NAME, COSTS, DISCOUNT, STATUS.
- Никаких операций изменения тарифов или договоров; стоимость COSTS пока выводится как есть без предположений о периоде, скидках и НДС.
- Подключение Oracle Thin без клиентских DLL; при необходимости можно указать установленный 64-bit Oracle Instant Client.
- Тесты используют только фиктивные данные, реальные подключения из CI не выполняются.
- Функции VPN и обновления из 3.0.15 сохранены.

Ограничения RC: реальная Oracle-сессия и форматы курсоров пока не проверены; режим поиска Ula и итоговая стоимость требуют сверки на тестовых клиентах. Перед распространением сотрудникам необходима проверка доступа в Oracle с разрешёнными учётными данными.
