LinkVideo VPN — план автоматических облачных резервных копий

Цель
----
Резервные копии VPN не должны зависеть от того, запущен ли LinkVideo.Helper на компьютере сотрудника. Helper остаётся интерфейсом ручного управления, а ежедневные копии делает постоянно работающий центральный сервис.

Предлагаемая схема
------------------
1. Отдельный LinkVideo VPN Backup Agent на постоянно работающей Linux VM/сервере.
2. Agent раз в сутки подключается к каждому vpn*.linkvideo.ru через RouterOS API.
3. Получает тот же FULL snapshot, что умеет Helper: PPP Secret, profiles, NAT/firewall, pools, routes, scripts/scheduler и т.д.
4. Из нормализованной конфигурации считается SHA-256.
5. Если конфигурация сервера не изменилась с прошлого запуска — новый полный снимок не загружается, в журнал пишется «без изменений».
6. Если конфигурация изменилась — создаётся новая версия снимка.
7. Перед отправкой чувствительные данные шифруются на Backup Agent. Ключ шифрования не хранится на MikroTik и не раздаётся рабочим компьютерам.
8. Зашифрованная копия отправляется в S3-совместимое Object Storage с включённым versioning.

Пример структуры
----------------
vpn-backups/
  vpn01.linkvideo.ru/
    2026/08/15/20260815_030000_FULL.json.enc
    2026/08/15/manifest.json
  vpn02.linkvideo.ru/
    ...

Политика
--------
- Проверка всех серверов: ежедневно, например 03:00.
- Дополнительный снимок: перед установкой/обновлением LV Automation.
- Ручной снимок одного сервера: из Helper.
- Ручной снимок всех серверов: из Helper.
- Хранение истории: настраиваемое; например ежедневные версии + более длинное хранение месячных контрольных точек.
- Отчёт: последний успешный backup, изменился/не изменился, SHA-256, размер, ошибка.

Почему не загружать прямо с каждого MikroTik
-------------------------------------------
Чтобы не хранить облачные ключи доступа на каждом VPN-сервере и не размножать облачную логику на RouterOS. MikroTik отвечает за L2TP и локальную LV Automation, Backup Agent — за централизованный backup.

Что добавить в Helper после появления Agent API
------------------------------------------------
- «Облачные копии» на странице VPN-серверов.
- Для каждого VPN: Последняя копия / Изменений нет / Ошибка / размер.
- Кнопка «Создать облачную копию этого сервера».
- Кнопка «Создать облачную копию всех».
- Просмотр истории снимков.
- Скачивание/восстановление выбранной версии с отдельным подтверждением.
