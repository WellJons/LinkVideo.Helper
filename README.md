# LinkVideo.Helper

Внутренний рабочий инструмент LinkVideo для управления VPN-клиентами и RouterOS, работы с архивом видеонаблюдения и диагностики.

## Текущая ветка

**3.0.7** — новый интерфейс LinkVideo.Helper 3.x с сохранением рабочей бизнес-логики предыдущих версий.

Основные возможности:

- создание и поиск L2TP-клиентов на VPN-серверах LinkVideo;
- управление PPP Secret, NAT-портами и паролями;
- контроль конфликтов внешних NAT-портов;
- мониторинг нагрузки VPN-серверов;
- автономная LV Automation на RouterOS;
- состояния клиентов: активная, спящая, карантин, кандидат в архив, отключена вручную, активность неизвестна;
- полные резервные копии VPN-конфигураций;
- скачивание и диагностика видеоархива;
- автоматическое обновление приложения.

## Быстрый запуск из исходников

Windows + Python 3.12:

```bat
run.bat
```
