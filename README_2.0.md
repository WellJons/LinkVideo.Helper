# LinkVideo.Helper 3.0.5

Полная переработка LinkVideo.Helper 1.1.2. Для пользователя приложение по-прежнему называется **LinkVideo.Helper**, версия текущего релиза — **3.0.5**.

## Интерфейс и синхронизация 3.0.5

В «Поиск и управление» карточка клиента больше не открывается отдельным окном: выбор результата плавно сжимает список в левую колонку и открывает карточку в той же рабочей области. Изменения портов/учётки сразу отражаются в карточке и списке результатов; выбранный клиент тихо обновляется раз в 15 секунд. Выбранный NAT-порт показывается одной плашкой, новые порты выделяются и копируются отдельно. Сортировка VPN-клиентов сделана сегментами «Старые / Новые / По серверу». На странице VPN-серверов можно отдельно выгрузить выбранный сервер или сделать полный снимок всех серверов.


## Основные разделы

- **Создание клиента** — проверка логина, автоматическая подстановка следующего свободного логина, создание одной или нескольких L2TP-учёток и NAT-портов.
- **Поиск и управление** — поиск по логину на всех активных VPN-серверах или по внешнему порту на выбранном сервере; управление паролем, PPP Secret, NAT-портами и текущей VPN-сессией.
- **Скачать архив** — B2O + Nimble DVR timeline, поиск текущего/резервного/исторического vcore, скачивание всех реально найденных интервалов в MP4 с понятными стадиями и прогрессом.
- **Диагностика архива** — точные DVR-разрывы, переезды, сравнение камер одного адреса и других камер vcore, а также автоматический вывод вероятной стороны проблемы: камера, адрес клиента, сервер/vcore, переезд или недостаточно данных.

## VPN-серверы

По умолчанию встроены:

- `vpn01.linkvideo.ru` … `vpn10.linkvideo.ru` — Россия;
- `rb-vpn01.linkvideo.ru` — Беларусь;
- `kz-vpn01.linkvideo.ru` — Казахстан.

Белорусский и казахстанский серверы выбираются вручную. Автоматический выбор сервера с минимальной нагрузкой использует только российские VPN-серверы. Дополнительные серверы добавляются в настройках и сохраняются через QSettings.


## VPN Automation 2.1.2

В разделе **VPN-серверы** Helper может не только показывать нагрузку и делать FULL backup, но и централизованно устанавливать служебную LV Automation на RouterOS. Скрипты хранятся на самом VPN-сервере и работают независимо от компьютера сотрудника.

Безопасная последовательность: FULL backup → «Установить LV» → «Last Seen» → наблюдение → отдельное включение `Q ON`. LV-Aging после первой установки всегда выключен. Ручное отключение из Helper получает состояние `M` и никогда не отменяется AutoRestore.

Lifecycle: `A` — Active, `S` — Sleeping 30+, `Q` — Quarantine 90+, `R` — Archive candidate 365+, `M` — Manual disable, `U` — неизвестный Last Seen.

## Интерфейс

Сохраняется функциональная компоновка 1.1.2, но с новым визуальным языком, анимациями и responsive-поведением:

- создание — форма сверху, результат снизу;
- поиск — результаты слева, карточка выбранного клиента справа;
- архив — параметры/период слева, сохранение справа, скачивание снизу;
- диагностика — параметры сверху, большой отчёт снизу;
- настройки используют широкую рабочую область, а не узкую колонку по центру.

На больших окнах контент получает умеренные боковые отступы, но не превращается в маленькую центральную форму. На узких окнах колонки перестраиваются, чтобы элементы не обрезались.

Темы из старого Helper сохранены. Нажатия, копирование, загрузка и завершение операций имеют визуальную обратную связь.

## Производительность

- Главное окно показывается до тяжёлых сетевых операций.
- Остальные страницы предварительно создаются после появления главного окна, чтобы не было краткого нативного flash-окна при первом открытии.
- Поиск логина по VPN-серверам выполняется параллельно.
- Для поиска используются облегчённые RouterOS-запросы; полная карточка клиента загружается после совпадения.
- Автовыбор сервера выполняет параллельную лёгкую проверку только российских серверов.

## Архив и время переездов

Наличие пропуска **не отменяет скачивание**. Helper скачивает всё найденное и отдельно показывает отсутствующие интервалы. Если отдельный подтверждённый DVR-участок не скачался по технической причине, остальные участки продолжают загружаться.

Период вводится во времени камеры. Журнал `reserve-transfers` трактуется как UTC+7 и сопоставляется через epoch. Например, событие камеры `05:03` в UTC+3 соответствует записи переезда `09:03` в UTC+7.

## Диагностика причины разрывов

Диагностический движок не выдаёт стандартный список советов. Он строит вывод по фактам выбранного периода:

- совпадения разрывов у камер одного адреса;
- совпадения у других камер текущего vcore;
- переезды `reserve-transfers`;
- точные DVR-интервалы и время начала/окончания gap.

Если данных недостаточно, Helper прямо сообщает, что точную сторону определить нельзя, вместо выдуманной причины.

## Сборка Windows

```bat
build_onedir.bat
BUILD_RELEASE_3.0.5.bat
```

Для полного набора релизных файлов:

```bat
prepare_release.bat
```

Результат создаётся в `release_upload`. Перед сборкой выполняются синхронизация версии, self-check и core tests.

`tools\ffmpeg.exe` необязателен. Если положить его туда до сборки, PyInstaller включит FFmpeg в приложение. Если его нет, Helper сможет получить компонент перед первым сохранением архива.

## Обновление с 1.1.2

Inno Setup использует прежний AppId, поэтому 2.0 устанавливается как обновление существующего Helper. Пользовательские QSettings и вручную добавленные VPN-серверы не удаляются. Название EXE, ярлыка и приложения — **LinkVideo.Helper**.

## Безопасность проекта

В релиз не должны попадать приватные SSH-ключи, старые патчи, `build`, `dist`, `__pycache__` и локальные данные диагностики. Старые страницы обслуживания серверов, Zabbix-интерфейс и проверка клиента в 2.0 не входят.
