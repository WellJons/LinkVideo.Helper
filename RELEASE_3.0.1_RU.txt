LinkVideo.Helper 3.0.1 — UI Polish

Что исправлено после первого UI Foundation:
- возвращена тема «Розовое молочко»;
- LinkVideo 2026 и LinkVideo Light теперь разные темы;
- исправлен календарь в тёмных темах;
- секунды в новых периодах архива по умолчанию 00;
- исправлено обрезание результатов поиска;
- карточка клиента использует всю доступную высоту страницы;
- компактный список найденных клиентов больше не пытается показывать слишком длинную строку.

Для проверки без компиляции запустить run.bat.
Для финальной сборки использовать BUILD_RELEASE_3.0.1.bat.
