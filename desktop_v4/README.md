# LinkVideo.Helper 4.0 — Electron Preview 1

Экспериментальная ветка. Не устанавливается поверх 3.x, не меняет QSettings старой версии, не публикует установщик или автообновления. Новый пользовательский профиль Electron. Визуальная основа — подход Nexora: Chromium / CSS / Web Animations API, а не перенос игровых модулей.

## Запуск на Windows

Из корня checkout ветки v4/electron (Python 3.12, Node.js 22+):
```powershell
python -m pip install -r requirements.txt
cd desktop_v4
npm install
npm start
```

Если Python не в PATH, перед npm start задайте $env:LV_HELPER_PYTHON полным путём к python.exe. Для локального ознакомления есть отдельный демонстрационный режим, без сетевых запросов и фиктивных серверных метрик.

## Готовые сценарии
- Реальный вход через существующую проверку RouterOS /login + /user, отказ при неподходящей группе; только встроенные доверенные серверы. Пароли не сохраняются.
- Поиск VPN-клиентов по логину или порту через FastSearchService, явные частичные ошибки, отображение состояния и портов без передачи паролей клиентов.
- Список встроенных серверов и анализ выбранного через VPNService.analyze_server_quick.
- Темы, анимации, навигация, изолированное сохранение настроек оформления. Reduced motion учитывается.
- Узкий IPC Electron и Python stdio RPC; нет открытого HTTP-порта, произвольного исполнения команд и операций записи. Текущая версия закрывает сессию завершением Python процесса.

## Проверки
Из корня: python -m unittest desktop_v4.test_worker
Из desktop_v4: npm run check

## До выпуска
Полный перенос рабочих операций, независимой авторизации CRM/B2O, архивов, шаблонов, диагностики, фоновых задач, базы настроек, кастомных серверов, прогресса и отмены, миграции и обновлений. Требуются тесты Windows/Electron и реальные проверки внутри сети LinkVideo; не заменяет стабильную версию. Не переносим существующие рабочие пароли в новый профиль автоматически.
