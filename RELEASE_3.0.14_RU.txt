LinkVideo.Helper 3.0.14

Исправление обновления
- Версия изменена с 3.0.13 на 3.0.14: ранее новая функциональность была опубликована с уже использованным номером 3.0.13, поэтому автоматическое обновление не определялось на компьютерах с 3.0.13.
- Обновление устанавливается полным LinkVideo.Helper_Setup.exe через официальный канал LinkVideo.Helper.Updates; проверяются SHA-256, ProductVersion, Windows release-gate.
- Установщик закрывает процессы Helper, атомарно заменяет Program Files и пересоздаёт штатные ярлыки. Настройки, пароли и локальные данные сохраняются.
- Если после установки пользовательский закреплённый ярлык всё ещё запускает прежнюю копию, следует открыть программу по пути C:\Program Files\LinkVideo.Helper\LinkVideo.Helper.exe и проверить v3.0.14.

Интерфейс 3.0.14
- «Новый Агент»: выбор ориентации четырьмя оформленными плитками; предустановки битрейта и ручной ввод без системных стрелок; удобный список часовых поясов.
- «Клиенты и тарифы»: увеличено окно подбора, добавлена внутренняя карточка с контуром, улучшены фильтры и высота списка тарифов. Убрана ненужная кнопка копирования выбора.
- «Поиск и управление»: после открытия клиента большая поисковая форма плавно сворачивается. Вместо неё отображается компактная навигация с возвратом к поиску; карточки поднимаются вверх.
- Подтверждение реальных изменений в тарифах и настройках камер сохранено.

Вкладки и функции, включённые в релиз
- «Новый Агент»: новый двухколоночный интерфейс, диагностика неполных ответов agent-vcore, поддержка постраничного поиска LD-камер.
- Превью найденной камеры через B2O, поиск точного серийного номера: Россия (оператор 241), Беларусь и Казахстан.
- Повторное применение ориентации и битрейта с актуализацией параметров без нового поиска камеры, обновление превью.
- Создание VPN-клиентов, работа с B2O-клиентами и тарифами, актуальный интерфейс и остальные исправления предыдущих RC-сборок.

Контроль поставки
- Не переиспользовать версию уже опубликованной стабильной сборки для нового исходного кода.
- Прямой RC-установщик предоставляется для ручной проверки перед публикацией стабильного канала.
