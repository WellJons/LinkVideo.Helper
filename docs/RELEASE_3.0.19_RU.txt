LinkVideo.Helper 3.0.19 — исправление установки обновлений

- Исправлен сценарий обновления с запущенной программы, когда Windows сообщала
  «cannot rename LinkVideo.Helper to LinkVideo.Helper.rollback: file in use».
- Установщик освобождает унаследованную рабочую папку до запуска с правами
  администратора и передаёт безопасный каталог TEMP процессу после UAC.
- Перед заменой старого Helper установщик завершает связанные процессы,
  проверяет фактическое завершение и повторяет переименование только при
  временной блокировке файлов Windows.
- Удалена кнопка «Удалить текущую версию» из мастера обновления. Ранее она
  переключала мастер на удаление и не продолжала установку новой версии.
- Установка по-прежнему использует резервную папку для отката при сбое,
  настройки и локальная библиотека ответов сохраняются.
- Исправления применяются к новому установщику версии 3.0.19.
- Версия включает функциональность 3.0.18, VPN/B2O, архив, шаблоны ответов.

Важно: если предыдущая попытка обновления завершилась ошибкой, новую
версию 3.0.19 можно установить поверх существующей, без удаления данных.
