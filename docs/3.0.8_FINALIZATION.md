# LinkVideo.Helper 3.0.8 — functional finalization

This branch is the working area for the remaining 3.0.8 functionality. It is not a release branch and must not publish public updates before the checklist is completed and manually accepted.

## Blocking work

- [ ] LV Automation: resilient install/update/start/stop across RouterOS variants; partial-install repair; useful diagnostics.
- [ ] Multi-VPN search: one unreachable/slow server must never block usable results or leave the UI overlay hanging.
- [ ] Archive: prefer real DVR/vcore hosts from the selected playlist/chunks interval; reserve/fallback only when needed; deterministic diagnostics.
- [ ] Updater: GitHub-first channel remains inactive until release; patch/full-setup selection and integrity checks stay covered by regression tests.
- [ ] Installer/uninstaller: separate LinkVideo-style installer/uninstaller implementation, preserving upgrade compatibility and user data choices.
- [ ] Regression/CI: every change passes the full release preflight and Windows Setup build before any final tag is moved.

## Explicitly not a release signal

A green CI build on this branch only means the build is technically reproducible. Public `LinkVideo.Helper.Updates`, Google Drive bridge publication, and the final `v3.0.8` tag are release actions and happen only after functional testing is complete.
