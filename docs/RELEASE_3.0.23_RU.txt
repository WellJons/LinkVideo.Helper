LinkVideo.Helper 3.0.23 — Обновление проверки фоновой задачи VPN (закрытая тестовая сборка)

- Исправлено сообщение «Планировщик сообщил об успехе, но задание не найдено».
  После подтверждения UAC задание проверяется с теми же правами администратора.
- При ограничении прав на чтение задания в обычном окне Helper
  показывается подтверждённый администратором статус, а не ложная ошибка.
- Добавлена кнопка «Проверить с правами администратора» для заданий,
  созданных предыдущей версией 3.0.22, без удаления или пересоздания.
- В настройках доступны время последней синхронизации и количество
  успешных/ошибочных VPN-серверов, без раскрытия защищённых настроек.
- Фоновая задача, сохранённая в Windows, продолжает работать без окна Helper.
- Период 6 / 12 / 24 часа и полный резерв Google Sheets сохранены.

Только для ручного тестирования владельцем.
НЕ опубликовано в общем канале автообновлений и не предлагается сотрудникам.
Реальный запуск задачи после установки необходимо проверить вручную.
