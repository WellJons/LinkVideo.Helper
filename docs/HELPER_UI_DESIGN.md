# LinkVideo.Helper — единая система оформления Desktop

Статус: **первый этап внедрён в PR**, эксплуатационная проверка Windows обязательна.

## Референс

Визуальный язык согласованного концепта: тёмная боковая панель, чистые
карточки, светлая рабочая поверхность, один выразительный акцент. Полноценное
desktop-приложение на PySide6, без браузерной оболочки и стороннего CDN.

### Общие правила

- Разделы остаются в левом меню и открываются без перезапуска окна.
- Сохраняются существующие роли AdminChats/системного администратора,
  API-вызовы и сигналы. Отсутствие кнопки в UI никогда не служит механизмом
  авторизации.
- Текст заголовков и действий всегда виден, иконки только дополняют его.
- Светлые темы: белые рабочие карточки на мягком фоне; тёмные темы: карточки
  темнее фона, но достаточно контрастны.
- Sidebar сохраняет графитовую основу во всех темах, активный пункт окрашен
  акцентом выбранной темы. Не заливать всю поверхность оранжевым.
- Обязательны hover/focus/disabled/busy/empty/error/success состояния;
  клавиатура, выделение и прокрутка должны сохраняться.
- Анимации короткие, не блокируют операции и отключаются в настройках.
- Пароли клиентов показываются только после явного действия пользователя.
  Копирование выполняется по отдельной кнопке, не логируется.

## Карта экранов

| Раздел | Изменение | Следующая приёмка |
| --- | --- | --- |
| Вход | Фирменный векторный фон, карточка, статус и shake для неверного пароля | Неверный/верный пароль, старая запись, пропавшая сеть |
| Настройки | Вкладки «Внешний вид», «Архив», «VPN-серверы», «О программе», предпросмотр | Все темы, изменение списка серверов, масштабирование |
| Создание клиента | Нумерованные этапы, ясное пустое/успешное состояние | Создание 1/нескольких, проверка логина, прогресс и ошибка |
| Поиск и управление | Поисковая панель остаётся видимой, портовая статистика, скрытый пароль | Поиск логина/порта, переходы и все операции с NAT |
| Скачивание/диагностика архива | Общие карточки/кнопки/состояния через theme.py | Длинные операции, отмена, FFmpeg/Curl |
| VPN-клиенты/серверы | Единые карточки, темизация навигации и элементов | Графики, таблицы, доступ AdminChats, синхронизация Sheets |

## Не делать без отдельной проверки

- Подменять реально используемые RouterOS операции фиктивными REST-запросами.
- Подставлять вымышленные значения состояния VPN, NAT, синхронизации.
- Публиковать Setup на основании одного UI-макета или статических тестов.
- Отключать функции/права при рефакторинге настроек или навигации.
