# План централизованных резервных копий VPN

Резервные копии VPN не должны зависеть от того, запущен ли LinkVideo.Helper на компьютере сотрудника. Helper остаётся интерфейсом ручного управления, а автоматические копии должен делать постоянно работающий центральный сервис.

## Предлагаемая схема

1. Отдельный LinkVideo VPN Backup Agent на постоянно работающей VM/сервере.
2. Agent по расписанию подключается к каждому `vpn*.linkvideo.ru` через RouterOS API.
3. Получает полный snapshot: PPP Secret, profiles, NAT/firewall, pools, routes, scripts/scheduler и другие необходимые разделы.
4. Из нормализованной конфигурации считается SHA-256.
5. Если конфигурация не изменилась — новый полный объект не загружается, в журнале фиксируется `без изменений`.
6. Если изменилась — создаётся новая версия снимка.
7. Перед отправкой чувствительные данные шифруются на Backup Agent. Ключ шифрования не хранится на MikroTik и не раздаётся рабочим компьютерам.
8. Зашифрованная копия отправляется в S3-совместимое Object Storage с versioning.

Пример структуры:

```text
vpn-backups/
  vpn01.linkvideo.ru/
    2026/08/15/20260815_030000_FULL.json.enc
    2026/08/15/manifest.json
  vpn02.linkvideo.ru/
    ...
```

## Политика

- проверка всех серверов — ежедневно;
- дополнительный снимок — перед изменением/обновлением LV Automation;
- ручной снимок одного или всех серверов — из Helper;
- история хранения — настраиваемая;
- отчёт по каждому серверу: последний успешный backup, изменился/не изменился, SHA-256, размер и ошибка.

## Почему не выгружать прямо с MikroTik

Так облачные ключи доступа не приходится хранить на каждом VPN-сервере и размножать облачную логику по RouterOS. MikroTik отвечает за L2TP и локальную LV Automation, центральный Agent — за резервное копирование.

## Что можно добавить в Helper после появления Agent API

- `Облачные копии` на странице VPN-серверов;
- статус последней копии для каждого VPN;
- ручной запуск копии одного/всех серверов;
- просмотр истории;
- скачивание выбранной версии;
- восстановление только с отдельным подтверждением и предварительной проверкой.
