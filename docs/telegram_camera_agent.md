# Telegram-агент камер LinkVideo (экспериментальный, выключен по умолчанию)

Это отдельный **локальный** процесс, а не автоматически включённая функция GUI.
Работает только при действующей сессии B2O в LinkVideo.Helper **того же пользователя Windows**.
Стабильный выпуск 3.0.15 не изменяется.

## Запуск для тестирования

1. Создайте бота через официальный @BotFather. **Не публикуйте токен в GitHub, в логах и переписке.**
2. Получите числовые Telegram ID сотрудников, которым разрешён доступ.
3. Войдите в «Админку» в LinkVideo.Helper на этом компьютере.
4. В отдельном терминале PowerShell, в исходном окружении проекта:

```powershell
$env:LINKVIDEO_TELEGRAM_BOT_TOKEN = 'ТОКЕН_ОТ_BOTFATHER'
$env:LINKVIDEO_TELEGRAM_ALLOWED_IDS = '123456789,987654321'
python -m linkvideo_vpn_helper.services.telegram_camera_agent
```

Не сохраняйте токен в постоянных переменных системы или исходниках.
Выполните `Remove-Item Env:\LINKVIDEO_TELEGRAM_BOT_TOKEN` после остановки.

## Команды в **личном чате**

- `/client 89527430240` — камеры России по точному логину владельца, до 20 результатов, до 4 превью.
- `/camera 167024` — краткая карточка и фоновый четырёхсекундный RTSP-замер (по одной камере).

Запросы принимаются **только** от числовых ID в allowlist и только из личного
чата владельца ID, не из групп. API B2O и камера должны быть доступны с того
компьютера, где запущен бот. При отсутствии FFmpeg замер FPS/битрейта может
быть недоступен. Токены B2O и RTSP-ссылки в Telegram не отправляются.

**Текущие ограничения:** поиск клиентов пока реализован для России.
Беларусь/Казахстан потребуют переиспользования аутентифицированной CRM-сессии.
Перезапуск процесса сбрасывает последние выбранные камеры. Доступ к боту не
означает автоматический доступ к камерам: B2O всё равно проверяет права
учётной записи Helper.

Фактическую правильность транскода нельзя установить по одному
`id_transcoding_server`. Пока показываются только настройки B2O и
предупреждение, если правила транскодирования не заданы. Введите правила
по оператору, тарифу и модели камеры, прежде чем включать зелёную/красную
проверку соответствия.

Для постоянного запуска, управления доступом и аудита сначала нужен
отдельный способ хранения и ротации токена бота и тест с вашим ИБ-специалистом.


## Правила проверки транскода

Пока правила не настроены, Helper показывает только параметры B2O без
ложного сообщения «транскод неверен». Для проверки можно задать JSON-правила
в настройках приложения `QSettings("LinkVideo", "LinkVideo.Helper")`,
ключ `camera/transcode_rules_json`:

```json
{
  "tariffs": {
    "742": {
      "video_codec": "H.264",
      "audio_codec": "AAC",
      "transcoding_server": 17
    }
  }
}
```

Это **пример формата**, а не реальные требования тарифа 742. Укажите
фактические значения по внутреннему регламенту LinkVideo. Также допускаются
`"cameras": {"167024": {...}}` и `"default": {...}`. Правила для
конкретной камеры имеют приоритет над тарифом и общими настройками.
Параметры сравниваются с данными B2O, а не с фактическим декодированием FFmpeg.
При несовпадении появится пометка **«Несоответствие»** с причинами.

Адрес установки показывается из поля `address` (или другого документированного
поля адреса), если оно заполнено; `server_name` и `ip` камер не являются
почтовым/географическим адресом.
