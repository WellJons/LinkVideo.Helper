# Telegram-бот LinkVideo.Helper — версия RC

## Настройка в программе

В LinkVideo.Helper откройте **Настройки → Telegram-бот**.

1. Укажите публичную ссылку `https://t.me/ВашBot`.
2. Введите токен, выданный BotFather, **только в локальном поле программы**.
   Разработчику токен сообщать не нужно.
3. Нажмите **«Сохранить и включить бота»** и подтвердите запрос UAC.
4. Настройки устанавливают задачу Windows `LinkVideo.Helper.TelegramBot`,
   выполняемую от **LocalSystem при запуске компьютера**. Это отдельный
   фоновый процесс, который не зависит от запуска GUI и смены Windows-пользователя.
5. Бот хранит API-токен в `%ProgramData%\LinkVideo\Bot\secrets\config.json`,
   защищённый машинным Windows DPAPI и ACL только для SYSTEM/Administrators.
   В QR/ссылку, GUI-профиль и параметры запуска токен не записывается.

В настройках можно **добавить или удалить сотрудника по числовому Telegram ID**.
Поскольку Telegram не разрешает получить ID произвольного человека лишь
по `@username`, удобнее использовать кнопку **«Создать ссылку-приглашение»**.
Сотрудник открывает её и нажимает Start; запись о его допуске сохраняется в
общем SQLite-хранилище `%ProgramData%\LinkVideo\Bot\invites.sqlite3`.
По умолчанию приглашение одноразовое и действует 24 часа. Доступ после
первой активации сохраняется. Пользователь с обычной публичной ссылкой
бота **не получает доступа к командам**.

Каждое изменение списка сотрудников, приглашение и настройка токена требует
подтверждения UAC, чтобы обычные пользователи общего компьютера не смогли
незаметно изменить права бота. Для просмотра текущего списка повышенные
права не нужны.

**Важно:** установленная служба — технически задача Windows Task Scheduler,
а не SCM-служба. Результат для пользователя тот же: она запускается после
старта Windows и не закрывается вместе с рабочим окном Helper. При обновлении
EXE установщик повторно запускает уже настроенную задачу; при удалении Helper
задача также удаляется.

## Возможности и ограничения

Текущий код бота реализует личные Telegram-чаты с допуском по приглашениям:

- `/start`, `/help` — проверка доступа и справка.
- `/client ЛОГИН` — камеры клиента России, список и до четырёх превью.
- `/camera ID` — данные выбранной камеры, RTSP-замер и транскод при наличии
  действующего B2O-доступа.

**Независимая авторизация к B2O ещё не настроена.** Учётная запись
сотрудника, который запустил GUI, не переносится в LocalSystem: это
сознательное ограничение безопасности. Поэтому бот после установки
может принимать приглашения и команды, но запросы камер сообщат об
отсутствии B2O-сессии, пока не будет отдельно согласован безопасный
способ доступа сервера к API. Для работы без общей B2O-учётной записи
нужен отдельный авторизованный шлюз или разрешённая сервисная идентичность.
Использование «последнего вошедшего пользователя» недопустимо.

**Создание VPN по Telegram ещё не подключено.** Перед включением потребуется
обособленный разрешённый путь записи к MikroTik, журнал операций и
подтверждение. Просмотр камер не даёт права создавать VPN.

Бот работает по HTTPS long polling и не требует открытых входящих портов.
Приватный SSH-ключ тестового медиасервера и пароль в EXE не включены.
На закрытом компьютере разрешите доступ к `api.telegram.org:443`.
Перед эксплуатацией выполните испытание под несколькими Windows-сессиями
и настройте сохранение/ротацию журналов.

## Безопасность

Доступ по ссылке не равнозначен тому, что Telegram-бот «скрыт»: публичный
username можно найти и переслать. Защита реализована одноразовым токеном
приглашения, автоматической фиксацией Telegram ID после активации и
отказом посторонним аккаунтам. Токен BotFather никогда не отправляйте
в сообщения или GitHub. Любое значение из ранее опубликованных
RTSP-паролей/SSH-паролей рекомендуется заменить.

## Проверка фонового запуска

В терминале Windows можно проверить:

```powershell
schtasks /Query /TN "LinkVideo.Helper.TelegramBot" /V /FO LIST
```

Ручной запуск настроенной задачи (после сохранения настроек):

```powershell
schtasks /Run /TN "LinkVideo.Helper.TelegramBot"
```

Задачу не следует запускать вторым экземпляром приложения с другим
токеном: Telegram `getUpdates` поддерживает только одного активного
polling-получателя на бот-токен.
