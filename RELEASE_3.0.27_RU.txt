LinkVideo.Helper 3.0.27 — срочное исправление создания VPN-клиентов

- Исправлено создание PPP-клиентов: NAT-проверки и аудит конфигурации теперь корректно принимают параметр start_ip. Ошибка "safe_create() got an unexpected keyword argument 'start_ip'" устранена.
- Убрано поле «Начальный Remote Address» из обычной формы создания клиента. Свободный IP выбирается автоматически из диапазона сервера с учётом PPP, активных подключений и NAT.
- Ранее сохранённые пользовательские начальные адреса серверов остаются действующими, чтобы не менять существующую адресную схему. Некорректные значения безопасно сбрасываются к стандартному началу пула.
- Проверяются создание одного и нескольких клиентов, проверка уникальности IP и NAT, совместимость обёрток создания, отмена/откат и режим выбора VPN-сервера.
- Все исправления LV2/Google Sheets и отключение LV История из 3.0.26 сохранены.

Доступно через официальный публичный канал обновлений.
