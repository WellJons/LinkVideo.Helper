LinkVideo.Helper 3.0.8 — переход на GitHub Updates

- Основной канал обновлений перенесён на публичный LinkVideo.Helper.Updates.
- Исходный LinkVideo.Helper остаётся приватным.
- Google Drive сохранён как резервный канал на переходный период.
- Манифест понимает как новое поле download_url, так и старое url.
- Добавлена схема дифференциальных патчей по исходной версии клиента.
- Если подходящего патча нет, всегда используется полный установщик.
- SHA-256 обязателен для безопасной публикации через GitHub Actions.
- Добавлен workflow, который копирует Release из приватного репозитория в публичный update-репозиторий.

Переход для уже установленных версий:
1. Один последний раз опубликовать 3.0.8 через текущий Google Drive manifest.
2. После установки 3.0.8 Helper начинает проверять GitHub первым.
3. При недоступности GitHub Helper автоматически проверяет старый Google Drive.
