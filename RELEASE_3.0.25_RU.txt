LinkVideo.Helper 3.0.25 — VPN IP и безопасная очистка неактивных учёток (закрытая тестовая сборка)

- Исправлена выдача PPP Remote Address: вручную назначенный высокий
  IP не заставляет Helper выдавать последующие адреса вслед за ним.
- В разделе «Создание клиента» доступно поле «Начальный Remote Address».
  Можно задать стартовый IP для каждого VPN-сервера отдельно.
  По умолчанию используется 172.16.0.1 — начало исторических
  таблиц VPN. Старый автоматически сохранённый старт 172.16.1.176
  мигрирует на 172.16.0.1; остальные ручные значения сохраняются.
- Выбирается первый свободный IPv4 от заданного начала, внутри
  того же диапазона /16. Выдача .0/.255 по умолчанию отключена;
  старые VPN-таблицы неоднородны: vpn01/vpn02/rb-vpn01 используют
  .0.255, а большинство серверов переходят с .0.254 на .1.1.
- Учитываются вручную и через Helper созданные адреса из PPP Secret,
  PPP Profile, активных соединений и адресов назначения NAT.
- Повторная проверка списка занятых IP перед созданием учёток
  уменьшает вероятность коллизии при одновременной работе операторов.
- Новое значение начального адреса сохраняется отдельно для VPN
  и автоматически подставляется при повторном выборе сервера.
- Добавлены регрессионные тесты вручную назначенного 172.16.1.130
  и корректной выдачи 172.16.0.1, 172.16.0.2 и т.д.,
  а также перехода с прежнего значения по умолчанию.
- Политика LV-Aging 2.1.1: 30 дней без активности — спящая;
  90 дней — отключение; 365 дней без подключения после прежнего
  использования — удаление; никогда не подключавшаяся учётка
  удаляется через 30 дней от достоверного начала LV-отсчёта.
- Ежедневный RouterOS LV-Aging не удаляет учётку преждевременно:
  сначала помечает её к удалению и блокирует подключение.
- Физическое удаление PPP Secret, связанных NAT и неиспользуемого
  личного PPP-профиля запускается только после подтверждённого
  резервирования данных клиента в Google Sheets. После удаления
  сведения остаются в «LV Удалённые», с причиной и журналом события.
  Восстановление удалённых учёток не предусмотрено.
- Если фоновая синхронизация Windows выключена или Google Sheets
  недоступен, удаление откладывается; учётка остаётся отключённой.
  Ручная успешная синхронизация также завершает очистку.
- Общие IP, чужие NAT-правила и используемые другими клиентами
  PPP-профили защищены от автоматического удаления.
- Добавлены автономные регрессионные тесты сроков, резервной копии,
  общей адресации и освобождения только принадлежащих клиенту портов.
- Включены предыдущие исправления версии 3.0.24:
  LV Automation 2.1.0 (обновляется до 2.1.1), короткие комментарии, корректные проверки
  копии RouterOS, интерфейс фонового резервирования 3.0.23.

Только для ручного тестирования владельцем.
Никаких публичных GitHub Releases, автообновлений и изменений на
реальных RouterOS-серверах при сборке не производится.
