LinkVideo.Helper 3.0.26 — LV2, Google Sheets и интерфейс Terminal // Code

- Исправлено распознавание LV1/LV2 для всех VPN-серверов, включая новые серверы с LV-автоматикой.
- В VPN-клиентах и Google Sheets выровнены состояния активности, сна и карантина.
- Исправлена передача даты последней активности RouterOS last-logged-out; подтверждённая дата не заменяется на «Никогда».
- Для удалённых клиентов восстановление дат возможно только по сохранённым достоверным данным RouterOS/LV; неизвестная история не выдаётся за отсутствие подключений.
- Резервное копирование Google Sheets больше не запускает самостоятельную очистку PPP/NAT.
- Отключена запись в «LV История», чтобы уменьшить количество бесполезных событий и запросов Google Sheets; старые записи не удаляются.
- Поиск VPN-клиентов работает по действующим учёткам RouterOS, без поиска удалённых и автоматического восстановления из архива.
- Лист «LV Удалённые» и резервные снимки для учёта и аудита сохранены.
- Добавлена тема Terminal // Code и улучшено оформление интерфейса; текущая тема существующих пользователей сохраняется.
- Добавлены проверки и тесты безопасной синхронизации, без внесения изменений на действующие MikroTik при установке Helper.

Автоматическое обновление доступно через официальный публичный канал LinkVideo.Helper.Updates.
