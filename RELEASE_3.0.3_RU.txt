LinkVideo.Helper 3.0.3 — Archive Fast Route

Главное изменение: скачивание архива больше не начинает перебор сотен b2o-vcore.

Порядок поиска:
1. Данные камеры из B2O.
2. playlist_dvr_range текущего server_name.
3. nested/chunks playlist, как у web-player.
4. Фактический DVR определяется из URI медиасегментов выбранного периода.
5. Только при неполном покрытии проверяются reserve-transfer.
6. Последний fallback использует только реальный реестр серверов B2O и накопленную историю; генерации vcore1..500 нет.

Вкладка со списком «Архивные серверы» из Настроек убрана: сотруднику полный список не нужен.

Для теста: run.bat
Для релизной сборки: BUILD_RELEASE_3.0.3.bat
