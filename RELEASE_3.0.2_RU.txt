LinkVideo.Helper 3.0.2 — Theme Polish

Основное:
- сохранён новый интерфейс 3.0;
- все названия цветовых тем приведены к русскому интерфейсу;
- удалены темы «Персиковая» и «Лесная»;
- старые сохранённые ключи этих тем автоматически мигрируют на актуальные;
- исправлена работа нативных Qt-элементов при смене темы через синхронизацию QPalette;
- спиннер, переключатели и график трафика больше не используют жёстко заданный розовый/серый цвет;
- блок портов/учёток при создании клиента получил мягкую акцентную поверхность вместо случайного серого фона;
- карточка клиента получила отдельную семантическую поверхность;
- палитры LinkVideo 2026, Розового молочка, Светлой LinkVideo и тёмных тем выровнены по контрасту.

Для проверки без компиляции: run.bat
Для финальной сборки: BUILD_RELEASE_3.0.2.bat
