LinkVideo.Helper 3.0.12

Обновление
- Исправлено скачивание обновлений на Windows-компьютерах, где Python/OpenSSL не мог построить цепочку сертификата GitHub и показывал CERTIFICATE_VERIFY_FAILED / unable to get local issuer certificate.
- Проверка TLS не отключается: UpdateService использует системные корневые сертификаты Windows вместе с актуальным CA-bundle certifi и продолжает обязательно проверять сертификат и имя узла.
- Одинаковый защищённый TLS-контекст используется и для update-manifest, и для загрузки Setup/Patch.
- Ошибка TLS теперь выводится понятным сообщением с подсказкой проверить дату/время Windows, корневые сертификаты и HTTPS-инспекцию антивируса/прокси.
- Усилен встроенный silent-updater: перед изменением Program Files он подтверждает фактическое завершение процессов LinkVideo.Helper и не начинает замену runtime, если это не удалось.
- В критическом patch-пути ProductVersion читается напрямую через Win32 version.dll, без запуска PowerShell и случайных таймаутов холодного старта.

Интерфейс
- Выпадающий список выбора метода скачивания архива полностью оформлен через палитру активной темы.
- QComboBox и popup больше не используют системную синюю Windows-подсветку; добавлены тематические hover/focus/selected/disabled состояния.
- Оформление применяется ко всем темам Helper, а не только к одной цветовой схеме.

Доставка 3.0.12
- Для установленной 3.0.11 публикуется дифференциальный patch 3.0.11 -> 3.0.12 через встроенный updater, без запуска мастера установки.
- Полный LinkVideo.Helper_Setup.exe остаётся доступен для чистой установки и ручного восстановления.
- Перед публикацией Setup и patch проходят SHA-256, ProductVersion и полный Windows release-gate.
