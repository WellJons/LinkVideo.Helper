LinkVideo.Helper 3.0.17 RC — десктопное обновление для Windows

НОВОЕ
1. VPN-клиент → камеры B2O.
   - При открытии карточки VPN-клиента автоматически ищутся камеры
     по точному логину аккаунта в Админке и сверяются с его портами.
   - Суффиксы VPN-учёток _1, _3 и подобные убираются ТОЛЬКО при
     определении исходного логина B2O. Сам VPN-логин не изменяется.
   - Можно указать другой B2O-логин вручную и повторить сверку.
   - Камера показывается напротив порта, только если B2O действительно
     вернул этот порт в карточке камеры и подтвердил владельца аккаунта.
   - Неоднозначные и неполные результаты не выдаются за точные связи.
     Все запросы чтения B2O идут в фоне, интерфейс не блокируется.
   - Требуется действующая авторизация «Админка».

2. Шаблоны ответов.
   - Отдельный раздел в боковой панели.
   - Создание, редактирование, удаление, поиск по названию/тексту,
     категории, избранное, копирование готового текста.
   - Локальное прикрепление изображений и импорт текстовых абзацев DOCX.
   - Шаблоны хранятся в SQLite профиля Windows, сервер не используется.
   - При импорте Word один файл становится одним шаблоном.

3. Улучшен внешний вид карточки VPN.
   - Пароль VPN-клиента отображается как обычная текстовая строка,
     наравне с логином и IP; текст можно выделить для копирования.
   - Убрана лишняя левая кнопка возврата: карточка клиента и блок
     управления начинаются на одинаковой высоте.
   - Поля с длинными подписями получили достаточную ширину.

ИЗ ПОДГОТОВЛЕННОЙ 3.0.16
- Авторизация MikroTik и Админки, улучшения камер, архивов и поиска.
- IP, с которого RouterOS видит L2TP-туннель (caller-id).
- Порты активных L2TP-учёток в статистике VPN-серверов.
- Telegram-бот в Windows-сборку НЕ включён; старые задачи бота
  из экспериментальных установок удаляются установщиком.

ПРЕДУПРЕЖДЕНИЯ
- Наличие активной VPN-сессии не подтверждает доступность камеры.
- Сверка B2O — только read-only. При отсутствии точного порта в
  данных камеры Helper не выдумывает соответствие.
- Тестовая RC-сборка не меняет стабильный канал автоматических обновлений.
- Проверить B2O на реальных аккаунтах и открыть карточку VPN на Windows
  необходимо до массового выпуска.
