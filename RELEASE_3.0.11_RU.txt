LinkVideo.Helper 3.0.11

- Возвращён выбор метода скачивания архива: FFmpeg, Curl и «Без звука».
- Современный автоматический поиск реального DVR/vcore сохранён для всех методов.
- FFmpeg больше не встраивается в установщик. При первом использовании FFmpeg программа скачивает компонент в %LOCALAPPDATA%\LinkVideo.Helper\tools, показывает реальный прогресс загрузки, проверяет файл и затем использует локальный кэш.
- Curl снова использует прямой Nimble export_mp4. При архиве с нескольких DVR Curl скачивает части напрямую; FFmpeg нужен только для корректной склейки нескольких MP4.
- Режим «Без звука» всегда сохраняет только видеодорожку с параметром -an.
- Исправлен release pipeline: единственный официальный Setup — новый LinkVideo.Helper_Setup.exe из installer_next. Старый Inno Setup больше не может попасть в GitHub Release.
- Установщик 3.0.11 не содержит ffmpeg.exe, поэтому обновление заметно меньше предыдущей временной сборки 3.0.10 с комплектным FFmpeg.
- Добавлен обязательный полный аудит исходного кода перед сборкой релиза: синтаксис, критические сетевые timeout-контракты, release/update chain, отсутствие секретов и конфликтующих runtime-модулей.
- Добавлены регрессионные тесты методов архива, загрузки/кэширования FFmpeg и контракта GitHub-публикации.

Перед публикацией релиз проходит полный Windows CI и ручную проверку обновления с установленной 3.0.10.
