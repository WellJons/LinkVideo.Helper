LinkVideo.Helper 3.0.11

Архив
- Возвращён выбор метода скачивания: FFmpeg, Curl и «Без звука».
- Сохранён автоматический поиск реального DVR/vcore для всех методов.
- FFmpeg больше не встраивается в Setup. При первом использовании он скачивается в %LOCALAPPDATA%\LinkVideo.Helper\tools, загрузка показывает реальный прогресс, файл проверяется и затем переиспользуется из кэша.
- Curl снова использует прямой Nimble export_mp4.
- Режим «Без звука» всегда исключает аудиодорожку через -an.
- Добавлена гарантированная остановка дочерних curl/ffmpeg-процессов при отмене и ошибках.

VPN / Google Sheets
- Синхронизация Google Sheets получила повтор безопасных запросов, увеличенный read timeout, ограничение параллелизма и connection pooling.
- Полная сверка использует одну подготовку схемы, запись блоками и circuit breaker вместо одновременного штурма Google API.
- Неопределённый результат append истории защищён Sync ID и не создаёт дубликаты.
- Серверные листы автоматически приводятся к актуальной 20-колоночной схеме с колонкой «Причина».
- LV2 lifecycle/retention остаётся авторитетным при синхронизации.

Обновление и установщик
- Единственный официальный Setup — LinkVideo.Helper_Setup.exe из installer_next; старый Inno release-path полностью удалён.
- Полный upgrade очищает старый runtime в Program Files перед распаковкой нового, не удаляя пользовательские настройки и LocalAppData-кэш.
- Исправлена основная проверка Windows ProductVersion в update_service, а не только compatibility-слой.
- Перед запуском обновления сохраняются проверки SHA-256 и ProductVersion.
- Setup не содержит ffmpeg.exe.

Проверка релиза
- Корень репозитория очищен от старых BUILD_RELEASE_*.bat, исторических README/RELEASE-файлов и устаревших сборочных путей; история остаётся в Git.
- Добавлен единый scripts/verify_release.ps1, одинаковый для локальной Windows и CI.
- Release gate включает: compile Python, полный source-аудит, все core regressions, Ruff, go vet, clean PyInstaller build, сборку Setup/Uninstall, compile differential patch pipeline, проверку ProductVersion и SHA-256.
- Точный произведённый Setup проходит side-effect-free --self-test: проверяются встроенный payload, очистка старого runtime, обязательные EXE и отсутствие встроенного FFmpeg.
- Результат проверки фиксируется в verification.json.
- Actions artifacts больше не являются частью release-chain. Для версии используется один приватный draft RC, который заменяется следующей успешно проверенной сборкой вместо накопления старых артефактов.
- Тяжёлый Windows CI запускается только для явной rc/** ветки, final v* tag или вручную, а не на каждом development-коммите.

Перед публичной публикацией обязательна ручная RC-проверка на Windows: обновление с установленной 3.0.10, запуск программы, все три метода архива, первая/повторная загрузка FFmpeg, Google Sheets и основные операции RouterOS/VPN.
