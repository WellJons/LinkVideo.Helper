LinkVideo.Helper 3.0.15

Исправление запуска Windows
- Устранён путь запуска фоновых консольных процессов, в котором ранее сохранялся флаг CREATE_NEW_CONSOLE: теперь вспомогательные процессы запускаются без окон терминала.
- Помимо CREATE_NO_WINDOW применяется STARTUPINFO / SW_HIDE; существующие параметры вызова и перенаправление потоков сохраняются.
- Защита включается до создания QApplication, перед проверкой сохранённых учётных данных и открытием основного интерфейса.
- В течение первых 60 секунд в штатный журнал записываются только имена исполняемых файлов дочерних процессов (не аргументы, пути, пароли или токены), чтобы при повторении проблемы отличить вызовы Helper от сторонних служб.
- Новые регрессионные тесты для Windows проверяют скрытие консольных процессов и сохранение параметров вызывающего кода.

Исправления интерфейса 3.0.15
- В подборе тарифов восстановлено числовое поле «Дней хранения»: 7, 14, 30 и другие значения снова видны, вручную вводится 0–3660 дней.
- Вкладка «VPN-клиенты» больше не запускает полное сканирование при открытии, возвращении на неё или изменении серверов. Сбор данных происходит только по кнопке «Проверить серверы».
- Тяжёлая вкладка VPN-клиентов не создаётся заранее при запуске приложения.
- Управление клиентом: кнопки перераспределены в две колонки, при небольшой ширине окна карточки располагаются друг под другом без обрезания.

Остальные функции версии 3.0.14 сохранены без изменений:
- Новый Агент: поиск камер, превью, ориентация, битрейт и время/NTP.
- Клиенты и тарифы, VPN-поиск и управление, создание клиентов, диагностика архива и обновления.

Версия 3.0.15 проходит отдельную RC-проверку перед публикацией в канал остальных сотрудников.
